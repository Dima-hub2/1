Общая постановка задачи: необходимо реализовать консольное приложение, которое имеет примитивный текстовый интерфейс, определенный студентом. В приложении потребуется добавить объект в список, просмотреть содержимое списка, а также продемонстрировать использование полиморфизма.
Задача заключается в том, что вам потребуется разработать некий «реестр» объектов. Требуется создать дерево наследования, в соответствии с вариантом, а также создать базовый класс, в котором будут определены основные методы. Требуется продемонстрировать использование полиморфизма, в функционале, определенном для классов из варианта. Функционал определяется студентом. Для этого можно создавать дополнительные классы. 

Варианты заданий
1.	Студент, преподаватель, человек, заведующий кафедрой.
